# 🎮 Life RPG - Геймификация продуктивности

Превратите свою жизнь в увлекательную игру! Устанавливайте цели, выполняйте квесты, прокачивайте персонажа и отслеживайте прогресс.

## 🚀 Быстрая установка (2 минуты)

### Способ 1: Через Netlify Drop (самый простой)

1. **Скачайте проект:**
   - Откройте файл `download.html` в браузере
   - Нажмите кнопку "📦 Скачать ZIP-архив"
   - Дождитесь автоматической загрузки

2. **Распакуйте архив:**
   - Найдите скачанный файл `life-rpg.zip`
   - Распакуйте его (правый клик → "Извлечь" или двойной клик)

3. **Загрузите на хостинг:**
   - Откройте [app.netlify.com/drop](https://app.netlify.com/drop)
   - Перетащите **папку dist** в окно браузера
   - Дождитесь загрузки (10-30 секунд)
   - Получите ссылку вида: `https://ваш-сайт.netlify.app`

4. **Установите на телефон:**
   
   **iPhone:**
   - Откройте ссылку в Safari
   - Нажмите "Поделиться" (квадрат со стрелкой)
   - Выберите "На экран Домой"
   - Нажмите "Добавить"
   
   **Android:**
   - Откройте ссылку в Chrome
   - Нажмите три точки ⋮ в правом верхнем углу
   - Выберите "Добавить на главный экран"
   - Нажмите "Установить"

### Способ 2: Через GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com)
2. Создайте новый репозиторий
3. Загрузите содержимое папки `dist`
4. Перейдите в Settings → Pages
5. Выберите ветку `main` и папку `/ (root)`
6. Сохраните настройки
7. Через 2-3 минуты получите ссылку: `https://ваш-username.github.io/имя-репо`

### Способ 3: Локально на компьютере

Если у вас установлен Node.js:

```bash
# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev

# Откройте http://localhost:3000 в браузере
```

## 📱 Функции приложения

### 🎯 Цели
- Создавайте цели по категориям: финансы, тренировки, спокойствие, обучение, творчество
- Устанавливайте стартовые замеры и целевые показатели
- Отслеживайте прогресс с визуальными индикаторами
- Автоматический расчет оставшихся дней до дедлайна

### ⚔️ Квесты
- 12 ежедневных заданий в 7 категориях
- Награды в виде монет и опыта за выполнение
- Категории: прогулки, медитация, цифровой детокс, социальные взаимодействия, обучение, творчество, время наедине

### 🛒 Магазин
- Покупайте скины для аватара (10 вариантов)
- Выбирайте фоны приложения (8 тем)
- Зарабатывайте монеты выполняя квесты
- 3 бесплатных фона + 5 премиум

### 📝 Дневник
- Ведите заметки и записывайте результаты
- Привязывайте записи к конкретным целям
- Хронологическое отображение всех записей
- Фиксируйте замеры и прогресс

### 🔥 Серии
- Отсчет дней подряд без пропусков
- Визуальный календарь последних 7 дней
- Push-уведомления о задачах
- Напоминания при пропуске дня

### ⭐ Прогресс персонажа
- Система уровней и опыта (XP)
- 8 достижений для разблокировки
- Визуальный индикатор прогресса
- Награды за выполнение квестов и целей

## 💡 Советы

- **Первый запуск:** Начните с выполнения ежедневных квестов для получения первых монет
- **Серии:** Старайтесь не пропускать дни - серия даёт мотивацию
- **Цели:** Создайте 1-2 цели для начала, не перегружайте себя
- **Магазин:** Копите монеты на крутые скины и фоны
- **Дневник:** Записывайте прогресс - это помогает отслеживать результаты

## 🐛 Проблемы и решения

**Приложение не загружается:**
- Проверьте интернет-соединение
- Очистите кэш браузера
- Попробуйте другой браузер

**Данные не сохраняются:**
- Проверьте, не включён ли режим инкогнито
- Убедитесь, что разрешено использование localStorage

**Уведомления не работают:**
- Разрешите уведомления в настройках браузера
- Проверьте настройки уведомлений на устройстве
